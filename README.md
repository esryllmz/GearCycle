# GearCycle

GearCycle is a portfolio-grade microservices platform for managing the
intake, inspection, repair, refurbishment, reusable-part recovery, resale
preparation, and responsible recycling lifecycle of electronic devices.

## Project Status

The project is currently in the domain and architecture definition phase.

## Planned Technology Stack

### Backend
